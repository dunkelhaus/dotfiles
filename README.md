# dotfiles

Holds all dotfiles used for local environment configuration, such as the WezTerm config, ZSHRC, and the complete neovim config.

The neovim config uses a plugin manager called lazy.nvim, which is installed automatically if not already present

This also includes support for Copilot Chat, and has LSPs configured primary for python and go.
Currently supports go for neotest, support for python testing to come.
